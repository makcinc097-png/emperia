ИМПЕРИЯ — заготовка Telegram Mini App для кликабельного города

Содержимое:
- web/index.html — экран города с прозрачными областями нажатия;
- web/city_3d.png — изображение города.

ВАЖНО:
1. Mini App должен быть размещён на HTTPS-хостинге.
2. В BotFather настройте Menu Button / Web App на HTTPS-адрес страницы.
3. В текущем bot_v3.py пока НЕ подключён обработчик web_app_data и URL Mini App.
   Поэтому кнопка «Улучшить» в этом шаблоне отправит JSON боту, но бот пока не выполнит улучшение.
4. После получения HTTPS-ссылки можно безопасно добавить кнопку открытия Mini App и обработчик,
   который будет вызывать существующую игровую логику улучшений. Не заменяйте базу данных.

Координаты областей нажатия — приблизительные, в процентах от изображения 1254x1254.
Их можно подправить в CSS (#farm, #sawmill, #quarry, #house, #barracks).
